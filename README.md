## 续费 200 元值不值：先把额度机制算明白

值不值取决于你的月调用量，而搞懂调用量，得先弄明白额度怎么扣。

额度按“模型调用次数”计算，一次提问往往对应多次调用。官方给的参考是：简单任务约 5–10 次，复杂任务 10–30 次起步。粗略换算一下，按简单任务每次 8 次调用算，90,000 次/月大约能支撑一万多次提问，摊到每天三百多次；如果任务偏复杂、一次吃掉 20 次调用，每天也有一百多次的量。个人开发者日常写码，这个量级多数情况够用；整天开着 agent 跑任务的重度用户，就得盯着三重上限规划着用了。

5 小时额度的恢复机制值得单独讲，因为它和很多人的直觉不一样：额度是滚动恢复的。上午 10:00 用掉 100 次，15:00 这 100 次自动回来；11:00 用掉 200 次，16:00 恢复。上午用猛了不用等到半夜，下午还能接着干。周额度每周一凌晨重置，月额度在每月订阅日重置。

对照物是按量计费。官方给 Coding Plan 的定位就是“按量付费的成本可控替代方案”；有第三方测评对国际站版本做过估算，重度用户走按量 API 每月花费在 100–420 美元以上，而套餐只要 50 美元/月。国内价格体系不同，逻辑是一样的：调用量大，订阅划算；调用量小，按量更省。

判断方法可以很朴素：翻一下你过去的按量账单或用量统计。每月调用连套餐额度的零头都用不到，续费就是花钱买安心；如果每月已经稳定跑出几万次调用，200 元的续费价依然比按量便宜。算完觉得划算，[👉 以当前标准价订阅 Pro 套餐](https://common-buy.aliyun.com/coding-plan?userCode=5eqf8rny)。

## 比折扣更影响钱包的几件事

最要紧的三条：不退款、Key 用错会被按量扣费、用途越界可能被封。都写在官方条款和 FAQ 里，但很容易被忽略。

**不支持退款。** 官方在订阅前须知里写得很直白。别抱着“先试试看”的心态冲动下单。

**API Key 别配错。** 这是最容易产生计划外开销的地方：Coding Plan 的额度只能用套餐专用 Key（sk-sp- 开头）加 coding.dashscope.aliyuncs.com 的接口地址来抵扣。要是误用了百炼通用 Key（sk- 开头），系统会把调用识别成按量付费，等于一边交着订阅费、一边被扣 API 费。官方 FAQ 专门列了这条，配置时多看一眼 Key 的前缀。

**用途有边界。** 套餐仅限在交互式编程工具中使用，自动化脚本、程序后端、批量调用都在禁止之列，违规可能导致订阅暂停或 Key 被封；账号共享同样会导致权益受限。订阅费按月交，被封了等于白交。

**名额要抢。** 每天上午 9:30 补充名额，先到先得。想订阅的时段显示无名额，第二天同一时间再试。

## 常见问题

**以后还会有续费优惠吗？**
官方没有任何预告。从上线至今的规律看，优惠都是限时限量的活动型打法，结束就是结束，没有可参考的回归时间表。与其干等，不如按标准价算一笔账，划算就直接续。

**每月额度什么时候重置？**
月额度在每月订阅日零点重置；周额度每周一零点重置；5 小时额度滚动恢复，5 小时前用掉的量会自动回来。

**额度用完会被额外扣钱吗？**
不会。三重上限任何一项触顶，调用直接暂停，等额度恢复或重置后继续，不存在超额扣费。

**能退款吗？**
不能。官方明确 Coding Plan 服务不支持退款。

**为什么订阅了还被按量扣费？**
大概率是 Key 或接口地址配错了。检查用的是不是 sk-sp- 开头的套餐专用 Key，地址是不是含 coding.dashscope.aliyuncs.com 的那组。两套 Key 和地址互不通用，混用就会触发按量计费。
